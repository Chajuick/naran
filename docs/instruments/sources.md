## IPIP — TCI 대응 예비 척도, ipip.ori.org/newTCIKey.htm
- 퍼블릭 도메인. 개발자 표기 'preliminary'. 응답 1~5 (very inaccurate ~ very accurate), 역문항 6 − 응답
- 나란 선별: 각 기질 차원 8문항 (NS1·NS2 / HA1~HA4 / RD1~RD4 / P1~P4 퍼싯에서 고름). NS3 과소비·NS4 반항(세금·욕설)은 문화·맥락상 제외 — 선별 단축판이라 원 척도 신뢰도(α)를 그대로 주장할 수 없음
