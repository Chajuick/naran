# 1차 역번역 (블라인드, 원문 모름) — 요약 메모
- 대부분 원문과 의미 일치 (ECR-R 36문항은 거의 원문 그대로 복원됨)
- 두 갈래로 읽힌 문항: Q4 오른쪽, Q6 왼쪽, Q27(좌우 비대칭), Q28 오른쪽, Q31(공연 vs 발표), ANX8, ANX11(마음 vs 기분), ANX12, AVO13(의논 vs 함께 결정), NS5, P3(능력 vs 끈기)
- 원문과 어긋난 복원: ANX12 "scares people away"→"부담스러워하며 멀어짐"(추가 해석), P3 "Meet challenges"→"get difficult tasks done"(능력으로 읽힘), Q20 OK, Q29 OK

# 1차 응답자 — 63세 기혼 은퇴 남성 요약
- 최대 문제: ECR-R '연인' 반복 → 기혼자는 계속 '아내'로 바꿔 읽음, 쑥스러움. 안내가 '아내(남편)나 가장 가까운 사람'이길 원함
- 낯선 말: 양극 척도(안내), 선택지를 열어 둬요, 큰 그림, 감수, 허락, 진짜 내 모습, 몸이 먼저 나가요, 등을 떠밀어야, 딱 넘어갈 만큼
- 상황 안 맞음: Q8 시험, Q11 일, Q29 노는 쪽, NS2 모험, P7 기대받는 것 → 은퇴자에게 낯섦
- 역문항 섞임 안내 필요(부정문 AVO5·RD3에서 답이 뒤집힐 뻔)
- Q27·Q31 짝이 안 맞음, Q32 따옴표 어려움, HA8 누구에게 확인?, RD1 흔들림=슬픔? 모호

# 1차 응답자 — 44세 기혼 직장인 여성 요약
- 같은 핵심: '연인' 안내가 기혼자에게 헷갈림 → "배우자나 연인 등 가장 가까운 파트너 (없으면 가장 최근 관계)"
- 비슷해 보이는 쌍: ANX7·ANX9, AVO8·AVO9, AVO15·AVO16, AVO12·AVO13, NS7·NS8 (원 검사의 의도된 중복이 있는 문항 — 표현 차이를 더 주는 정도로)
- 짝 비대칭: Q6(기분 vs 바람), Q27, Q31 / 방향이 문항마다 달라 헷갈림 → 안내 필요
- 맥락 모호: HA4·HA5 '위험'이 무엇인지, HA8 누구에게 확인, RD1 누구의 불행, ANX14·ANX15(주제 이탈)
- 강도: P5 '절대'가 세서 응답 쏠림, P6 '완벽' 부정적 뉘앙스

# 1차 응답자 — 23세 대학생(연애 1회, 솔로) 요약
- 짝 비대칭이 가장 많이 걸림: Q4·Q6·Q27·Q29·Q31 / 방향이 문항마다 뒤집힘 → 안내 필요
- 연애 경험 적으면 상상으로 답함 → "지금 없다면 가장 최근(또는 떠올릴 수 있는) 관계"
- 중복 체감: ANX1·17·18, AVO4·8·9, AVO3·15·16, AVO10·13, NS5·6, NS7·8, HA6·7 — ※ 원 검사의 의도된 반복(신뢰도용)이라 문항 삭제 불가. 표현만 구분감 있게
- 극단어로 응답 쏠림: P5 '절대', RD8 '모두', P6 '완벽', RD1 '깊이' — ※ 원문 강도(never/everyone/perfect)를 낮추면 문항 의미가 바뀜 → 심리측정 검토로 판단
- 번역투: ANX2·ANX3·ANX13·ANX14

# 1차 국어 편집자 요약
- 설문 A: 양극이 같은 축에 있지 않은 쌍(Q2·Q6·Q24·Q28·Q30·Q31), 한쪽만 부정 수식어(자꾸·그냥 아무 데나·정신없이) → "같은 뼈대 + 반대말만" 원칙으로
- 겹말: 지금 현재, 앞으로의 미래, 그때그때 즉흥적으로, 연인과 함께
- 번역투: 스스로 허락하다, 지지, 만족시키다, 기대받다, 연애 관계에 대해, 눌러 담다(연어 부적절)
- '~하는 편이 좋아요'는 당위로 읽힘 → '~하는 게 편해요'
- 응답 척도 문구 해요체로 통일 (B가 해라체였음)
- ※ 편집자 제안 중 의미가 바뀌는 것(Q6 '칭찬으로 들려요', ANX15 연애 맥락 추가, P5 강도 완화)은 심리측정 검토와 대조해 판단

# 1차 심리측정(ITC 번안 기준) 요약 — 판정: 수정 후 사용
- 좌우 순서·역채점 표시·IPIP 원문/키 모두 원 척도와 일치 확인
- [상] ANX14 가정문("~하면")으로 바뀌어 변별력 저하 → 현재 진술로
- [중] 기질 퍼싯 라벨 오기(HA1 부정 정서, HA4 낮은 자기효능감, P2 유능감) / ANX8 '나 자신을 의심' 오독 / HA5 '도전' 추가(바람직성) / Q26 '연민' 동정 뉘앙스
- [하] Q4 '늘' 추가, Q6 '정확하게' 추가, Q18 '힘든' 추가, Q31 perform 약화, ANX6 '만큼'(양), ANX11 '나에 대한' 누락, AVO16 강도 약화, AVO18 really·needs, NS2, RD8 please, P7, 척도 문구 해요체
- 기질 선별: HA4·RD4 1문항, NS 규칙 측면 누락 → "Try to follow the rules" 추가 권고, HA8 Need reassurance는 ECR-R 불안과 겹침 → 교체 권고, RD5·RD7은 ECR-R 회피와 겹침(기록), TCI 점수라 부르지 말 것
