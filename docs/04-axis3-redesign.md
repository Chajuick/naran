# 04. 기준 축(③) 재설계 작업 노트

> 파일럿 1에서 ③이 0점(상쇄)으로 나온 문제를 고친다. 결론이 나면 02 문서에 반영하고 이 노트는 과정 기록으로 남긴다.

## 문제 진단 (v0.1)

| 문항 | 실제로 잰 것 |
|---|---|
| V09 연인 연락 | 대칭 (+ C 선택지는 '조율'인데 맥락 1로 채점 → 대칭을 지지하는 사람의 조율 답이 반대쪽으로 계산됨) |
| V10 더치페이 | **형평**(형편 따른 배려) — 대칭과 다른 가치 |
| V11 선후배 말투 | 대칭 vs 역할 |
| V12 요구-요구받음 | 대칭 vs 역할 |

→ "원칙 ↔ 맥락"이 **대칭(이중잣대 거부)**과 **형평(사정 따라 덜 내게)**을 섞었다. 대칭은 지지하고 형평엔 유연한 사람은 0으로 상쇄된다.

## v0.2 방향

**축 재정의: 대칭 ↔ 역할**

| 극 | 정의 | 덕목으로서의 근거 |
|---|---|---|
| **대칭** (−) | 내가 요구하는 건 나도 지킨다. 규칙은 쌍방이다 | 공정, 상호성, 이중잣대 거부 |
| **역할** (+) | 관계·역할·성향이 다르면 서로 기대하는 것도 다를 수 있다 | 역할 윤리, 위계·책임의 차이 인정, 개인차 수용 |

- 형평(더치페이)은 ③에서 **제외**. 대칭과 다른 차원이다.
- 🗨 조율 선택지는 "무엇을 향해 조율하나"로 채점한다. "같은 기준을 정해 둘 다 지키자" = 대칭 쪽.
- 원칙 유지: ③ 문항에 '실수·잘못'을 넣지 않는다 (①과 분리). 비대칭이 **그럴듯하게 정당할 수 있는** 상황만.
- ③(말로 지지하는 대칭)과 미러 지수(실제로 쓰는 대칭)를 비교하면 "말과 실제"가 나온다.

**V12 · 슬라이더** (유지, 극 이름만 변경)

### 라운드 1 (v0.2 후보 5문항) — 응답자 6명

| | R1 연인 연락 | R2 팀장 | R3 친구 장난 | V11 말투 | V12 요구 | 합 (−대칭/+역할) | 예상 |
|---|---|---|---|---|---|---|---|
| P1 부장 | B | C | B | 2 | 4 | **+1** | 역할 ⚠ |
| P2 개발자 | B | A | B | 4 | 2 | −6 | 대칭 ✓ |
| P3 교사 | C | B | B | 3 | 2 | −2 | 중간 ✓ |
| P4 반찬가게 | C | C | D | 2 | 4 | +6 | 중간~역할 ✓ |
| P5 대학원생 | A | A | B | 4 | 2 | −7 | 대칭 ✓ |
| P6 만든 사람 | A | A | B | 4 | 2 | −7 | 대칭 ✓ |

**발견**
1. **동등 관계 문항은 변별력 없음.** R3에서 5/6이 B, 4명이 "모범답안 보임". P1도 "친구는 같아야, 직장은 다르다". 동등 관계의 대칭은 거의 보편 가치 → 사람을 가르는 건 **위계 관계**. 동등 관계의 이중잣대 민감도는 MaxDiff(C05)와 미러 지수가 이미 담당.
2. **생각 vs 행동 혼재.** 4명이 "생각은 A, 행동은 B/C". "기회를 봐서 말해요"(R2-B)는 갈등회피(④ 조화)를 잰다 — P4가 R2-C를 고른 이유도 "따지기 피곤해서". 원칙 0-1 위반.
3. **역할 극 선택지가 합리화로 읽힘** ("그냥 받아줘요", "자연스러워요"). 덕목으로서의 근거(더 큰 책임, 경험, 보호)가 문구에 없다.
4. V11: 존댓말은 공정이 아니라 예절 관습이라는 지적 4명. V12: '요구'가 규칙인지 책임 범위인지 모호 4명 — 응답자들이 스스로 "규칙은 같아야, 책임 범위는 달라도"를 구분함 → 이 구분 자체가 좋은 문항 재료.
5. 필러로 넣은 ②(Q4)는 C(존중+사후 지원)가 6명 중 5명 → ②의 V05도 C 흡인력 과다. **별도 기록, 다음 ② 검토 때 처리.**

### 라운드 1 — 심리측정 검토 요약 (판정: 재설계 필요)

1. **지문이 곧 악덕 장면.** R1~R3 모두 "남에게 요구하고 자기는 안 지키는 사람" = C05 이중잣대. 역할 극이 "이중잣대 눈감기"로 읽혀 원칙 0-2 위반. 비대칭의 정당화 근거가 지문에 없음.
2. **대칭에 자기 이익이 섞임.** 응답자가 늘 손해 보는 쪽 → 원칙인지 손해 싫음인지 분리 불가.
3. **동등 관계의 '역할' 답 = 형평의 재유입.** (Fiske 관계모형: 대칭 = Equality Matching, 위치 역할 = Authority Ranking. 동등 관계의 차등은 개인 필요 기반이라 다른 계열)
4. **행동 선택지 → 갈등회피·직설성 혼입** (R2-B ④, R2-C ①, R3-C ⑤, R3-D 방향 오분류).
5. **검증 설계 결함**: 나이·직급으로 예상 위치를 정해 나이를 검증한 셈. → 목표 신념만 다른 인물 쌍 + 판별용 인물(갈등회피+대칭, 관용+대칭)으로 교체.
6. ③에 🗨 두지 말 것 (조율 지수와 기계적 상관 + 흡인력). 조율 지수는 ①②④⑤ 4개로.
7. 신뢰도: 위계로 통일 시 4문항 α≈0.57, 혼합 시 0.31~0.41. → **③은 데이터 전까지 3단계(대칭/균형/역할) 표시**.
8. V11 존댓말 = 세대·언어관습 측정 → 탈락. V12는 역할 극에 '의무'를 넣어 개정.
9. ③ 내용의 미러 쌍이 없음 → 연인 연락 상황을 미러 M4로 옮기는 안 (결정 보류: +2화면).

## v0.3 — 위계·위치 관계로 통일

**축: 대칭 ↔ 위치**

| 극 | 정의 |
|---|---|
| **대칭** | 나이나 자리가 달라도 서로 지킬 규칙은 같아야 한다 |
| **위치** | 자리·나이·책임이 다르면 권한도 의무도 다르게 정하는 게 정당하다 |

**작성 원칙**
- 비대칭은 **공개적으로 정해진 제도·관례**로 제시 (한 사람의 언행 불일치 X → 이중잣대 장면 X)
- 응답자 위치를 섞는다: 아래(N1) / 위(N2) / 관찰자(N3)
- 위치 극은 특권만이 아니라 **더 무거운 의무**도 포함 (N3)
- 모든 선택지는 판단 진술. 행동 진술·🗨 조율 선택지 없음
- 등급: 2 = 예외 없이 같아야/달라야, 1 = 원칙은 그렇되 일부 예외 허용

**N1 · SJT · 내가 아래**
> 우리 팀은 팀원은 9시까지 출근해야 하지만, 팀장은 외부 일정이 많아 출근 시간을 자유롭게 정한다. 이 차이는 처음부터 팀에 안내되어 있었다.

| | 선택지 | 가중치 |
|---|---|---|
| A | 같은 팀이라면 출근 규칙도 같아야 해요 | 대칭 2 |
| B | 기본 규칙은 같게 두고, 외부 일정 같은 예외는 팀원에게도 똑같이 인정돼야 해요 | 대칭 1 |
| C | 맡은 일이 다르니 어느 정도 차이는 납득할 수 있어요 | 위치 1 |
| D | 책임지는 자리가 다르면 규칙이 다른 게 맞아요 | 위치 2 |

**N2 · SJT · 내가 위** (검토안의 부모-자녀 지문은 "부모가 모범" 정답 흡인 우려로 교체)
> 내가 카페 매니저다. 아르바이트생에게 근무 중 휴대폰 사용을 금지했다. 나는 발주·거래처 연락 때문에 근무 중에도 휴대폰을 쓴다.

| | 선택지 | 가중치 |
|---|---|---|
| A | 금지했다면 나도 근무 중엔 똑같이 안 써야 해요 | 대칭 2 |
| B | 나도 원칙은 지키되, 업무상 필요한 사용은 아르바이트생에게도 똑같이 허용해야 해요 | 대칭 1 |
| C | 맡은 일이 다르니 어느 정도 차이는 괜찮아요 | 위치 1 |
| D | 매니저와 아르바이트생은 책임이 달라서 규칙도 다른 게 맞아요 | 위치 2 |

**N3 · SJT · 관찰자, 위치가 더 무거운 의무를 지는 경우**
> 회사 선후배가 함께 점심을 먹는다. 둘의 형편은 비슷하다. 선배는 "선배가 사는 거야"라며 늘 계산하려 한다.

| D | 윗사람이 더 베풀고 아랫사람은 예를 갖추는 게 자연스러워요 | 위치 2 |

**정의**: 수평 = 나이·연차와 상관없이 같은 발언권과 대우 / 연륜 = 먼저 오고 나이 든 사람을 앞세우는 질서와 예우가 맞다. 근거에 경험·공로·의무 금지.

**S1′ 발언 순서** — 어느 팀은 회의에서 연차가 높은 사람부터 차례로 의견을 말하고, 신입은 마지막에 말한다.
수평2 연차와 상관없이 누구나 먼저 말할 수 있어야 해요 / 수평1 순서는 그럴 수 있어도, 신입 의견도 똑같은 무게로 다뤄야 해요 / 연륜1 선배 의견부터 듣는 건 팀의 질서로 괜찮다고 봐요 / 연륜2 오래 몸담은 사람이 먼저 말하는 게 팀에 대한 예의예요

**S2′ 등산 모임 결정권** — 어느 등산 모임은 나이가 가장 많은 회원이 모임 일정을 정하는 게 관례다.
수평2 나이와 상관없이 일정은 모두 같이 정해야 해요 / 수평1 어른 의견을 먼저 묻는 건 좋지만, 정하는 건 다 같이 해야 해요 / 연륜1 다 같이 의견을 내고, 마지막 결정은 가장 연장자가 하는 게 좋아요 / 연륜2 가장 어른이 정하는 게 모임을 지키는 질서예요

**S3′ 휴가 우선권** — 어느 회사는 휴가 날짜가 겹치면 연차가 높은 사람이 먼저 고른다.
수평2 연차와 상관없이 신청 순서나 추첨으로 정해야 해요 / 수평1 연차를 조금 고려할 순 있어도, 매번 우선권을 주는 건 아니라고 봐요 / 연륜1 오래 다닌 사람에게 먼저 고를 기회를 주는 것도 괜찮다고 봐요 / 연륜2 오래 다닌 사람을 먼저 챙기는 게 회사의 예의예요

**S4′ 슬라이더** — 연륜: 나이나 연차가 많은 사람의 의견에 더 무게를 두는 게 맞아요 / 수평: 나이나 연차와 상관없이, 누구의 의견이든 같은 무게여야 해요
