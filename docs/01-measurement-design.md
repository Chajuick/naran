# 01. 측정 설계 (초안 v0.1)

> `00-brief.md`의 "진행 순서" 1~5단계에 대한 답. 6단계(문항 초안)는 이 문서 승인 후 `02-items-values.md`.

## 0. 먼저 정해야 할 큰 원칙 3가지

### 0-1. 가치 검사는 "내가 어떻게 행동하나"가 아니라 "나는 무엇을 옳다고 보나"만 잰다

브리프의 G(정서적 성숙)에는 두 가지가 섞여 있다.
- "나는 감정을 잘 조절한다" → 내 **행동/기질** (자기보고)
- "감정이 힘들다고 남을 공격해도 되는 건 아니다" → 내 **판단 기준** (가치)

둘을 한 척도에 섞으면 무엇을 쟀는지 해석할 수 없게 된다(구성개념 오염).
→ **가치 검사는 판단 기준만**. 내 행동·반응 경향은 기질·애착 모듈이 맡는다.
이렇게 나누면 교차해석이 오히려 강력해진다: *"감정 조절을 남에게 강하게 기대하지만(가치), 본인의 정서 반응성은 높은 편(기질)"* 같은 문장은 둘이 분리되어 있어야 나온다.

### 0-2. 축의 양 끝은 둘 다 '좋은 가치'여야 한다

"책임 ↔ 무책임"이면 누구나 책임 쪽을 고른다. "책임 ↔ **이해**"(사정을 헤아려줌)면 진짜 선택이 생긴다.
모든 축을 **덕목 vs 덕목**으로 설계 → 사회적 바람직성 편향을 구조적으로 줄인다. 결과도 자연스럽게 "누가 더 좋은 사람"이 아니라 "무엇을 먼저 보는 사람"이 된다.

### 0-3. 악덕 민감도는 축이 아니라 '순위'로 잰다

악덕을 Likert로 물으면 ("위선이 얼마나 싫은가요?") 다 7점이 나온다. 천장효과.
→ **최선-최악 선택(Best-Worst Scaling, MaxDiff)**: 4~5개 중 "가장 거슬리는 것 / 가장 덜 거슬리는 것"을 고르게 하면 전부 싫어도 **상대적 순위**가 강제로 드러난다. 짧고(한 화면 2탭) 심리측정적으로도 안정적이다.

## 1. 개념 중복 정리 (7개 후보 영역 → 5축 + 2개 순위 과제)

| 브리프 영역 | 처리 | 이유 |
|---|---|---|
| A 판단·지혜 | **해체** → 자기객관화·오류인정은 '진정성'으로, 독선·확증편향은 악덕 목록으로 | 독립 축으로 재기엔 상황 문항이 대부분 "현명한 답"이 뻔해짐. 대신 "자기에게 정직함"은 진정성의 안쪽 면 |
| B 책임·자기관리 | **축 1** (책임 ↔ 이해). 성실·꾸준함은 제외 | 성실·꾸준함은 가치가 아니라 행동 특성 → 기질(인내력)·성격(J/P)과 중복 |
| C 자율·존중 | **축 2** (자율 ↔ 보살핌) | 반대극을 '통제'가 아니라 '적극적 보살핌'으로 둬야 진짜 선택이 됨 |
| D 공정·상호성 | **축 3** (원칙 ↔ 맥락) + **자기-타인 미러 문항** | 이중잣대는 자기보고로 안 잡힘 → 같은 상황을 주어만 바꿔 두 번 묻고 차이를 계산 (§4) |
| E 진정성·소통 | **축 4** (솔직 ↔ 조화). "비공개 ≠ 기만"은 악덕 순위에서 분리 | 브리프의 핵심 뉘앙스(거짓 자체엔 관대, 조작적 거짓엔 민감)는 축이 아니라 악덕 카드를 쪼개서 잡는 게 정확 |
| F 관계·배려 | **해체** → 비가해·감사·평가절하는 덕목/악덕 순위로, 관용은 축 1의 반대극 | 배려는 대부분 축에서 이미 '반대극 덕목'으로 등장 (이해·보살핌·조화·헤아림). 별도 축이면 이중 계산 |
| G 정서적 성숙 | **축 5** (표현 ↔ 헤아림) — *남의 감정을 판단에서 어떻게 다루나*만 남김 | 원칙 0-1. 내 감정조절 능력은 기질 모듈로 |

### 최종 가치 구조

**Part 1 · 5개 가치 축 (덕목 vs 덕목)**

| 축 | 왼쪽 극 | 오른쪽 극 | 핵심 질문 |
|---|---|---|---|
| ① 책임 축 | **책임** — 상황은 설명이지 면책이 아니다 | **이해** — 사정과 성장 가능성을 넓게 본다 | 잘못이 있을 때 무엇을 먼저 보나 |
| ② 경계 축 | **자율** — 조언 후엔 그 사람 선택 | **보살핌** — 가까우면 적극적으로 개입 | 가까운 사람의 선택에 어디까지 들어가나 |
| ③ 기준 축 | **원칙** — 같은 규칙을 모두에게 | **맥락** — 관계·역할·상황별로 다른 기준 가능 | 규칙은 누구에게나 같아야 하나 |
| ④ 표현 축 | **솔직** — 거칠어도 진짜 마음이 낫다 | **조화** — 관계를 위해 다듬고 덮을 수 있다 | 진실과 관계 평온이 부딪히면 |
| ⑤ 감정 축 | **표현** — 감정은 말로 설명돼야 다룰 수 있다 | **헤아림** — 말 안 해도 감정 자체를 먼저 돌본다 | 감정은 판단에서 어떤 지위를 갖나 |

→ 결과 코드: 5글자 (예: 책임·자율·원칙·솔직·표현). 32조합 전부 이름 붙이지 않고, **가장 뚜렷한 2축 조합으로 유형명**(10개 내외) + 나머지는 수식어.

**Part 2 · 악덕 민감도 순위 (MaxDiff)** — 12개 카드

책임 전가·변명 / 자기합리화 / 통제·강요 / 거절 무시 / 이중잣대 / 위선 / 수동공격 / 감정을 무기로 쓰기 / 평가절하·조롱 / 호의를 당연시 / **조종하려는 거짓말** / **사적인 걸 숨기는 것(비공개)**

- 마지막 두 장이 핵심: 같은 '거짓/숨김' 계열을 의도별로 쪼갬 → "거짓 자체엔 관대, 조작엔 민감"이 순위 차이로 드러남.
- 비교용 "약한 악덕" 몇 장 섞음: 우유부단, 자기주장 부족, 무뚝뚝함 — 이런 걸 거의 신경 안 쓰는 사람을 구분하기 위해.
- 결과: 민감 Top 3~5 / 관대 Bottom 3.

**Part 3 · 사람을 볼 때 무엇을 보나 (MaxDiff)** — 10개 카드

도덕적 특성(책임감, 솔직함, 존중, 공정함, 따뜻함, 잘못 인정) **+ 비도덕적 매력**(유능함, 사교성, 유머, 카리스마)
- 비도덕적 매력을 섞어야 "도덕적 특성 중 뭐가 1등인가"만이 아니라 "**인간적 판단에서 도덕성 vs 매력의 비중**"이 나온다 (브리프: 성공·카리스마·재미는 우선순위 낮음).
- 결과: 중시 덕목 Top 3~5 / 덜 중요하게 보는 것.

### 과잉 위험은 문항이 아니라 '조합'에서 계산

| 조건 | 과잉 위험 문장 (예) |
|---|---|
| 책임 극단 + '책임 전가' 민감 1위 | 사정을 들을 여유 없이 결과로만 판단해 냉정해 보일 수 있어요 |
| 자율 극단 + 헤아림 낮음 | 존중이 방치처럼 느껴질 수 있어요 |
| 솔직 극단 + '평가절하' 민감도 낮음 | 솔직함이 상처로 전달될 수 있어요 |
| 이해 극단 + 원칙 낮음 | 기준이 흐려져 같은 일이 반복될 수 있어요 |
| 보살핌 극단 + '통제' 민감도 낮음 | 걱정이 상대에겐 간섭으로 느껴질 수 있어요 |

축이 양극 덕목이라 "균형"은 자연스럽게 중앙 = 두 가치를 다 쓰는 사람으로 해석된다. 부족/균형/과잉을 위해 별도 문항을 만들 필요가 없다.

## 2. 영역 간 변별성 검토

예상되는 상관과 대응:

| 쌍 | 우려 | 대응 |
|---|---|---|
| ①책임 ↔ ③원칙 | 둘 다 "엄격함" 일반요인으로 뭉칠 수 있음 | ①은 **잘못의 귀속**, ③은 **규칙의 대칭** 상황만 쓴다. ③ 문항엔 잘못/실수가 등장하지 않게 |
| ①이해 ↔ ⑤헤아림 | 둘 다 "온정" 요인 | ①은 **결과 평가** 시점, ⑤는 **감정이 표현되는 순간**의 상황으로 분리 |
| ②보살핌 ↔ ④조화 | 관계 중심 성향 | ②는 **타인의 선택**, ④는 **내 말의 내용**에 관한 상황 |
| 가치 축 ↔ 성격 T/F | T/F와 ④⑤가 겹칠 수 있음 | 겹침 자체는 정상. 다만 통합 해석에서 같은 신호를 두 번 세지 않도록 (§6) |

**솔직한 판단**: 문항 4개짜리 축은 내적 일관성(α)이 0.5~0.65 정도로 예상된다. 연구용 기준(0.7)엔 못 미친다. 그래서:
- 점수를 91점처럼 정밀하게 보여주지 않는다 → **5단계 구간**("뚜렷하게 책임 쪽 / 약간 책임 쪽 / 균형 / …")
- 축마다 **확신도**를 함께 표시 (§4)
- 데이터가 쌓이면 문항 단위로 교체 (§7)

이건 약점이 아니라 정직한 표시 방식이고, 토스식 "사람의 언어" UX와도 잘 맞는다.

## 3. 문항 수 / 시간 예산

| Part | 형식 | 개수 | 예상 시간 |
|---|---|---|---|
| 1. 가치 축 | 상황판단형 4지선다 12 + 양극 슬라이더 8 | 20 (축당 4) | ~4분 |
| 1+. 미러 문항 | 기존 상황의 주어만 바꾼 쌍 | +3 | ~30초 |
| 2. 악덕 순위 | MaxDiff 화면 (5장 중 최악/최선) | 6화면 | ~1.5분 |
| 3. 사람 볼 때 | MaxDiff 화면 | 4화면 | ~1분 |
| **합계** | | **33화면** | **6~7분** |

화면 수는 브리프 상한(30)을 살짝 넘지만, MaxDiff 화면은 탭 2번이라 체감은 25문항 이하. 미러 문항은 원 문항과 멀리 떨어뜨려 배치.

### 문항 형식 2종

**A. 상황판단형 (SJT) — 4지선다**
선택지마다 축 가중치. **주 가중치 ±2, 부 가중치 ±1까지, 한 선택지당 최대 2개 축.**
(그 이상 섞으면 축 간 인위적 상관이 생겨 변별성이 무너진다.)

```
친구가 같은 약속을 세 번째 어기며 진심으로 사과한다.
A. 진심이면 한 번 더 기회를 준다        → ①이해 +2
B. 사과보다 행동이 안 바뀐 게 문제다     → ①책임 +2
C. 이번엔 왜 그랬는지 사정부터 들어본다  → ①이해 +1, ⑤헤아림 +1
D. 바뀔 거라 기대하지 않고 거리를 둔다   → ①책임 +1, ②자율 +1
```

**B. 양극 슬라이더 — 5점**
두 덕목 진술 사이에서 위치 선택. 빠르고(모바일 엄지 1번) 양극 채점에 정확.

```
"누가 울고 있다면, 일단 그 사람 편에서 생각하는 게 맞다"
●────●────●────●────●
"우는 것과 그 사람 말이 옳은지는 별개다"
```

## 4. 채점 구조

```
축 점수 = Σ(선택지 가중치) → -100(왼쪽 극) ~ +100(오른쪽 극) 정규화
축 구간 = 5단계 (뚜렷/약간/균형/약간/뚜렷)
축 확신도 = 그 축 문항들이 같은 방향을 가리킨 비율
           (4문항 중 4개 같은 방향 → 높음 / 반반 → "상황에 따라 다름")
```

"상황에 따라 다름"은 오류가 아니라 **결과의 일부**로 보여준다 — "이 축은 상황마다 다르게 판단하는 편이에요."

### 미러 문항 → 기준 일관성 지표

같은 상황을 주어만 바꿔 묻는다.
```
(원) 연인이 바쁘다며 하루 연락이 없었다. 서운해해도 되나?
(미러) 내가 바빠서 하루 연락을 못 했다. 연인이 서운해해도 되나?
```
두 응답의 차이 = 자기-타인 기준 차이. 3쌍 평균 → **"기준 일관성"** 지표.
- 결과 표현은 비난조 금지: "나와 타인에게 거의 같은 기준을 써요" / "나에겐 조금 더 너그러운 편이에요" / "타인에게 더 너그러운 편이에요(자기에게 엄격)" — 후자도 중요한 정보다.
- 이 지표가 축 ③(원칙 선호)과 다르게 나오면 그 자체가 통합 해석 소재: "원칙을 중시한다고 답했지만 실제 판단에선 자신에게 조금 더 너그러워요." (브리프 지침 6: 가치관과 행동의 모순 지적)

### 응답 품질

- 소요시간이 지나치게 짧으면(문항당 <1.5초) 결과 상단에 "빠르게 답한 편이라 결과가 덜 정확할 수 있어요"
- 슬라이더 전부 같은 칸 → 동일 경고

## 5. 기준 사례(만든 사람)로 구조 검증

브리프의 가치관 목록이 이 구조에서 어떻게 잡히는지 미리 확인:

| 브리프 진술 | 잡히는 곳 | 예상 |
|---|---|---|
| 상황은 설명이지 면책 아님 / 사과는 행동 변화 | 축 ① | 뚜렷하게 책임 |
| 조언 후엔 그 사람 선택, 결과 책임은 안 짐 | 축 ② | 뚜렷하게 자율 |
| 나에게 적용한 규칙은 그 사람에게도 | 축 ③ + 미러 | 원칙, 기준 일관성 높음 |
| 거칠어도 솔직한 사람이 편함 | 축 ④ | 솔직 |
| 운다고 주장이 옳은 건 아님 | 축 ⑤ | 표현 |
| **상대가 상처받았다면 이유를 듣고 조절** | 축 ④⑤의 일부 문항 | **극단이 아니라 '약간'** — 이 뉘앙스가 살아야 구조가 맞는 것 |
| 거짓 자체는 관대, 조종용 거짓엔 민감 | Part 2 | '비공개' 하위권, '조종 거짓' 상위권 |
| 위선·수동공격·책임회피·이중잣대 | Part 2 | Top 4 |
| 자기주장 약함은 결함 아님 | Part 2 | '자기주장 부족' 최하위권 |
| 성공·사교성·카리스마·재미 우선순위 낮음 | Part 3 | 비도덕적 매력 4장 하위권 |
| 오해했다·미안하다 말하는 능력 | Part 3 | '잘못 인정' 상위권 |

→ 11개 진술 모두 구조상 측정 위치가 있다. 특히 "책임 중시하지만 상처엔 조절함"을 극단값이 아닌 **약간**으로 잡을 수 있는지가 문항 설계의 시험대.

**아직 안 잡히는 것**: "깊은 관계 > 넓은 관계" — 가치보다 기질(사회적 민감성)·성격(E/I) 영역. 교차해석 문장으로 처리.

## 6. 다른 3개 모듈 설계

### 저작권·상표 전제

| 원본 | 상태 | 이 앱의 처리 |
|---|---|---|
| MBTI | 상표·문항 저작권 (Myers-Briggs Co.) | "MBTI"로 검사를 칭하지 않음. **"이미 아는 유형 입력"** + 자체 4축 단축검사("성격 4축") 둘 다 지원 |
| Big Five (IPIP) | **퍼블릭 도메인** 문항 풀 | 성격 4축 문항의 기반으로 사용 |
| 애착 ECR-R / ECR-S | 연구용 공개 (비상업) | ECR의 2차원(불안·회피) 이론 구조를 따르되 문항은 자체 작성 권장 |
| 기질 TCI (Cloninger) | 저작권 (국내 마음사랑) | 4개 기질 차원 개념만 참고, 문항 자체 작성 |

> 개인/포트폴리오 단계에선 리스크가 낮지만, 공개 배포를 염두에 두고 처음부터 깨끗하게 간다.

### 성격 4축 (~16문항, 2~3분)
IPIP Big Five 중 4요인을 MBTI식 4축으로 매핑하는 것이 학계의 통상적 대응이다:
외향성 → E/I · 개방성 → N/S · 우호성 → F/T · 성실성 → J/P
→ 결과: 4글자 + 축별 퍼센트. **이미 아는 MBTI를 입력하면 검사 생략** (유입 장벽 ↓)
(Big Five의 5번째 '신경성'은 기질 모듈의 정서 반응성과 겹치므로 여기선 안 씀)

### 애착 (~12문항, 2분)
2차원: **관계 불안**(버려짐·확인 욕구) × **친밀 회피**(거리 두기·의존 불편)
→ 4유형: 안정 / 불안 / 회피 / 두려움-회피. **유형 + 2차원 좌표 둘 다 표시** (경계선 사람이 많아서 유형만 보여주면 오해 생김)

### 기질 (~16문항, 3분)
4차원 × 4문항: **자극 추구 / 위험 회피(정서 반응성) / 사회적 민감성 / 인내력**
- 인내력은 성격 J/P와, 사회적 민감성은 F/T·E/I와 일부 겹침 → §2와 같은 원칙으로 해석 시 중복 계산 금지

### 전체 사용자 부담
가치 6~7분 + 성격 2~3분(또는 입력 10초) + 애착 2분 + 기질 3분 = **최대 15분, 4개로 쪼개서 아무 순서로**. 하나만 해도 부분 프로필이 나오고, 모듈이 늘수록 통합 해석이 풍부해지는 구조 (점진적 공개).

## 7. 통합 해석 & AI 프롬프트

### 교차해석 규칙 예시 (가장 가치 있는 부분)

| 조합 | 문장 |
|---|---|
| 가치⑤ 표현 + 애착 불안 높음 | "감정은 말로 하자"고 생각하지만, 정작 불안할 땐 확인받고 싶은 마음이 커서 스스로도 그 기준을 지키기 어려울 때가 있어요 |
| 애착 회피 높음 + 가치② 자율 | 존중의 언어로 거리를 두는 편이라, 상대는 존중이 아니라 거절로 받아들일 수 있어요 |
| 기질 정서반응성 높음 + 가치① 책임 | 남에게 기대하는 감정 책임의 기준이 높은 만큼, 스스로 감정이 흔들릴 때 자책이 커질 수 있어요 |
| (기준 사례) "화나면 나중에 얘기하자 하고 떠남"이 성숙이라는 사람 + 상대가 애착 불안 | 커플 비교에서: 한쪽의 '절제'가 다른 쪽에겐 '버려짐'으로 느껴질 수 있음 |

규칙은 `조건 → 문장` 데이터 파일로 관리 (코드에 하드코딩 X). 초기 40~60개 목표.

### 프로필 직렬화
- 모든 결과를 하나의 JSON → base64 URL 해시로 공유 (서버 없음)
- 커플 비교 = 상대의 공유 링크/코드를 붙여넣기 → 두 프로필 로컬 비교 → 커플 분석 프롬프트 생성
- 응답 원본은 기기 밖으로 안 나감. 공유되는 건 결과 요약뿐
