# 02. 가치·관계윤리 검사 문항 초안 (v0.1)

> 구조는 `01-measurement-design.md` 참고. 이 문서는 문항·가중치·채점의 **원본**이고, 구현 시 `src/content/values.ts`로 옮긴다.

---

## 표기 규칙

축과 극 (가중치는 항상 **극 이름 + 숫자**로 적는다):

| 축 | 왼쪽 극 (−) | 오른쪽 극 (+) |
|---|---|---|
| ① 책임 축 `RESP` | **책임** | **이해** |
| ② 경계 축 `BOUND` | **자율** | **보살핌** |
| ③ 기준 축 `RULE` | **원칙** | **맥락** |
| ④ 표현 축 `CANDOR` | **솔직** | **조화** |
| ⑤ 감정 축 `EMO` | **표현** | **헤아림** |

- 상황판단형(SJT): 선택지당 주 가중치 ±2 또는 ±1, 부 가중치 최대 1개(±1).
- 슬라이더: 5칸 → 왼쪽 극 2 · 1 · 0 · 1 · 2 오른쪽 극.
- 슬라이더의 좌우 배치는 문항마다 섞는다 (아래 표의 '좌/우'는 **화면 배치**, 채점 극과 무관하게 키로 매핑). 같은 쪽만 누르는 습관이 한 극으로 쏠리지 않게.
- 화면에는 축 이름도 가중치도 보이지 않는다.

## Part 1 · 가치 축 (20문항)

### ① 책임 축 — 잘못이 있을 때 무엇을 먼저 보나

|---|---|---|
| A | 진심이라면 한 번 더 기회를 줄 수 있어요 | 이해 2 |

## Part 2 · 이럴 때 가장 거슬려요 (MaxDiff, 6화면)

화면 문구: **"이 중에서 가장 거슬리는 것 하나, 가장 괜찮은 것 하나를 골라주세요."**
악덕 단어(위선, 이중잣대…)는 그 자체로 나쁜 말이라 다 1등이 된다 → **행동 묘사**로 제시.

| # | 카드 문구 | 악덕 (내부 라벨) | 연결 축 |
|---|---|---|---|
| C01 | 잘못이 드러나면 상황이나 남 탓을 한다 | 책임 전가 | ① |
| C02 | 사과는 하는데 같은 행동을 반복한다 | 말뿐인 사과 | ① |
| C03 | "널 위해서"라며 내 선택에 간섭한다 | 통제 | ② |
| C04 | 싫다고 했는데 다시 조르거나 밀어붙인다 | 거절 무시 | ② |
| C05 | 남에게 요구하는 걸 자기는 안 지킨다 | 이중잣대 | ③ |
| C06 | 앞에서 하는 말과 뒤에서 하는 말이 다르다 | 위선 | ④ |
| C07 | 직접 말하지 않고 말투나 침묵으로 불만을 드러낸다 | 수동공격 | ④⑤ |
| C08 | 울거나 화를 내서 상대가 물러서게 만든다 | 감정 무기화 | ⑤ |
| C09 | 남을 깎아내려서 자기를 높인다 | 평가절하 | — |
| C10 | 남의 호의를 당연하게 여긴다 | 감사 없음 | — |
| C11 | 원하는 대로 움직이게 하려고 사실을 꾸며 말한다 | **조종하는 거짓** | ④ |
| C12 | 자기 사적인 일은 가까운 사람에게도 잘 말하지 않는다 | **비공개** (약) | ④② |
| C13 | 자기가 틀렸다는 걸 끝까지 인정하지 않는다 | 오류 불인정·독선 | ① |
| C14 | 결정을 잘 못 내리고 남에게 미룬다 | 우유부단 (약) | — |
| C15 | 싫어도 싫다고 잘 말하지 못한다 | 자기주장 부족 (약) | — |

- C11 ↔ C12: 같은 '감춤' 계열을 **의도**로 쪼갠 쌍. 둘의 순위 차이가 "거짓 자체에 대한 태도 vs 조작에 대한 태도"를 보여준다.
- (약) 3장: 대부분 하위로 가는 기준점. 이걸 상위로 올리는 사람은 '기질적 약점에도 민감한 사람'으로 구분된다.

### 블록 설계 (15장 × 각 2회 = 30칸, 5장씩 6화면)

| 화면 | 카드 |
|---|---|
| S1 | C01 C06 C09 C12 C14 |
| S2 | C02 C05 C08 C11 C15 |
| S3 | C03 C04 C07 C10 C13 |
| S4 | C01 C02 C03 C11 C12 |
| S5 | C04 C05 C06 C13 C14 |
| S6 | C07 C08 C09 C10 C15 |

- 모든 카드가 정확히 2번 등장. 1~3화면에서 함께 나온 쌍은 4~6화면에서 최대한 다시 만나지 않게 배치.
- C11과 C12는 S4에서 **정면으로 맞붙는다**.
- 화면 순서와 화면 안 카드 순서는 사용자마다 무작위로 섞는다.

### 채점

```
카드 점수 = (가장 거슬림 선택 수 − 가장 괜찮음 선택 수) / 등장 횟수(2)   → −1 ~ +1
```
- 2회 등장이라 점수가 5단계뿐 → 동점이 잦다.
- **동점 해소 화면 (조건부 1화면)**: Top 5 경계에 동점이 있으면 그 카드만 모아 "이 중 가장 거슬리는 것은?"을 한 번 더 묻는다. 동점이 없으면 생략.
- 결과: **가장 민감한 것 Top 3~5** / **비교적 관대한 것 Bottom 3**

```

기준 일관성 = 평균 d
```

| −0.5 ~ +0.5 | 나와 남에게 거의 같은 기준을 써요 |

## 축 점수 계산

```
축 원점수 = Σ 선택한 가중치 (왼쪽 극 −, 오른쪽 극 +; 부 가중치 포함)
축 만점   = 그 축 주 문항 4개의 최대 가중치 합 = 8
축 점수   = clamp(원점수 / 8 × 100, −100, 100)
```

| 축 점수 | 구간 표시 |
|---|---|
| ≤ −60 | 뚜렷하게 왼쪽 극 |
| −60 ~ −20 | 약간 왼쪽 극 |
| −20 ~ +20 | 균형 |
| +20 ~ +60 | 약간 오른쪽 극 |
| ≥ +60 | 뚜렷하게 오른쪽 극 |

**확신도** = 주 문항 4개 중 다수 방향과 같은 방향을 가리킨 문항 비율 (0인 응답 제외)
- 4/4 또는 3/3 → 확고해요
- 3/4 → 대체로 그래요
- 2/4 이하 → **상황에 따라 달라요** (결과 문장도 이걸 반영해 "이 축은 상황마다 다르게 판단하는 편이에요")

> 기준값(±20, ±60)은 임시. 지인 데이터로 분포를 본 뒤 조정한다.
