# 00. 프로젝트 브리프 (원 요구사항 보존본)

> GPT와의 긴 기획 대화(2026-10-01 이전)를 요약·보존한 문서. 설계 판단이 흔들릴 때 여기로 돌아온다.
> 이 문서는 "무엇을 원했는가"이고, "어떻게 만들 것인가"는 `01-measurement-design.md`.

## 이름

**나란** — "나란 이런 사람". 비교 기능에선 "나란히"로도 읽힌다.

## 한 줄

**검사하고 끝나는 심리테스트가 아니라, AI가 이해할 수 있는 나의 프로필을 만듭니다.**

나는 어떤 사람일까? 성격, 관계, 기질, 가치관을 한 번에 모아 나만의 심리 프로필을 만든다.

## 제품 형태

- 서버 없는 웹앱. 계산·저장 전부 클라이언트(localStorage). 계정 없음, DB 없음, API 비용 0.
- 톤: 네이버/토스. 흰 배경, 큰 문장 하나, 연회색 카드, 카드당 정보 하나, 그래프 절제.
  - "책임 91점"보다 **"내 선택은 내가 책임져야 해요 · 책임성 상위"** 처럼 사람의 언어로 번역.
- 모바일 우선. 한 화면 1문항 또는 짧은 묶음, 진행률 표시.
- 포트폴리오 소재로도 쓴다 (검사 설계 + 시각화 + 결과 개인화 + 인터랙션).

## 4개 모듈

| 모듈 | 보는 것 |
|---|---|
| 성격 (MBTI 스타일) | 정보처리·의사결정·생활방식 |
| 애착 | 친밀감·갈등·거리 조절 |
| 기질 | 감정 반응성·자극 추구·회피·지속성 |
| 가치·관계윤리 (자체 개발) | 어떤 덕목을 우선하고, 어떤 관계적 잘못에 민감한가 |

통합 프로필의 핵심은 **병렬 나열이 아니라 교차해석**:
> "독립적인 판단 성향이 강하지만, 관계에서는 상대의 선택권을 중요하게 보는 편입니다."

초기엔 규칙 기반 문장 조합(조건 → 문장). 일관되고 통제 가능.

결과 화면 구성 예: 한 줄 요약 → 생각하는 방식 / 관계 맺는 방식 / 갈등할 때 / 중요하게 보는 가치 / 스트레스 받을 때 / 잘 맞는 관계 / 주의할 점

## AI 프롬프트 내보내기 (핵심 차별점)

프로필을 ChatGPT·Claude·Gemini에 붙여넣을 수 있는 프롬프트로 생성 → 클립보드 복사.

- 목적별: 나를 깊게 분석 / 연애 스타일 / 갈등 패턴 / 일·업무 스타일 / 나와 상대 비교
- 커플 비교: 두 사람 프로필 → 공통점, 충돌 가치, 오해하기 쉬운 부분, 갈등 시 각자 원하는 반응
- 프롬프트에 넣을 분석 지침:
  1. 유형명 반복 금지
  2. 검사 간 연결·충돌 분석
  3. 강점뿐 아니라 맹점·과잉 가능성
  4. 병리화·진단 금지
  5. 근거 약한 부분은 추측이라고 명시
  6. 가치관과 실제 행동의 모순이 있으면 지적
  7. 연애·갈등·일·스트레스·의사결정 상황별 구체 설명
- 서두: "절대적 진단이 아니라 이해를 위한 참고자료로 사용할 것"

## 가치·관계윤리 검사 요구사항

### 철학

- "책임감이 중요하다고 생각하나요?" 식 자기평가 금지 → 누구나 '그렇다'를 고르므로 변별력 0.
- **서로 다른 덕목이 충돌하는 구체적 상황**에서 무엇을 우선하는지로 가치관을 추론.
- **덕목 중요도**와 **악덕 민감도**는 독립적으로 측정.
  - 예: 진정성은 중시하지만 거짓말 자체엔 관대할 수 있다. 비공개는 자율성. 반면 거짓이 책임회피·조종·현실왜곡·피해자화에 쓰이면 매우 부정적.
- 단순 양극화 금지. 덕목도 **부족 / 균형 / 과잉**이 있다 (책임 과잉→자기비난·냉정, 배려 과잉→자기희생, 정직 과잉→잔인한 솔직함, 관용 과잉→기준 없음).
- **누가 더 좋은 사람인가를 평가하는 검사가 아니다.** 각 가치구조의 장점과 한계를 균형 있게.
- 검증된 임상검사처럼 과장하지 않는다. 초기 명칭: "가치관·관계윤리 프로파일 테스트". 데이터가 쌓이면 변별도·내적일관성·요인구조로 개선.

### 후보 영역 (고정 아님, 재설계 가능)

- **A 판단·지혜**: 자기객관화, 신중함, 개방성, 오류 인정, 현실검증 / 반대: 독선, 확증편향, 자기기만, 성급한 단정, 감정을 사실처럼 취급
- **B 책임·자기관리**: 책임감, 성실, 자기조절, 행동 변화, 결과 수용 / 반대: 책임회피, 변명, 자기합리화, 반복 실수 후 무변화, 책임 전가
- **C 자율·존중**: 의사 인정, 거절권, 사생활, 선택권, 경계 / 반대: 통제, 강요, 거절 무시, 상대 감정을 대신 정의, "널 위해서" 개입
- **D 공정·상호성**: 같은 규칙, 형평, 권리-의무 균형 / 반대: 이중잣대, 특권의식, 자기에게만 관대
- **E 진정성·소통**: 자기 마음에 솔직, 직접 표현, 모르면 모른다, 상처받으면 상처받았다, 잘못하면 인정 / 반대: 위선, 자기기만, 좋은 의도로 포장, 수동공격, 알아서 알아주길 기대, 욕구를 명분으로 숨김. (※ 모든 사실 공개 ≠ 진정성. 말하지 않을 권리 존중)
- **F 관계·배려**: 불필요한 상처 안 줌, 공감, 협력, 체면 배려, 표현 조절, 호의에 감사 / 반대: 무시, 평가절하, 조롱, 상대를 채점, 호의를 당연시
- **G 정서적 성숙**: 감정조절, 충동억제, 좌절·거절 감내, 감정을 떠넘기지 않음, 설명 가능한 표현, 실수에서 학습 / 반대: 감정을 무기로, 울음·분노·침묵으로 통제, 거절당하면 평가절하, 피해자 위치로 이동, 감정에 따라 사실 재구성

### 형식

- 24~30문항, 4~7분, 모바일에서 피곤하지 않게.
- 상황판단형(4지선다) + Likert 혼합. 뻔한 문항 금지.
- 한 응답이 여러 지표에 작은 가중치 (예: B 선택 → 책임 +2 / 관용 −1 / 성숙 기대 +1).
- 역문항·반대 상황으로 응답 일관성 확인. 결과에 **응답 일관성 / 확신도** 표시.

### 결과 형태

핵심 유형명(예: 원칙적 자율형 / 관계조율형 / 관용적 공동체형) · 6~8개 지표 · 중시 덕목 Top 3~5 · 민감 악덕 Top 3~5 · 덜 중요하게 보는 덕목 · 관대한 영역 · 과잉 위험 · 관계에서 중요하게 보는 것 · 갈등 시 특징 · 잘 맞는/충돌하는 가치관

### 진행 순서 (요구됨)

문항부터 만들지 말고:
1. 개념 중복 정리 → 2. 대영역·하위요인 수 제안 → 3. 영역 간 변별성 검토 → 4. 24~30문항으로 얼마나 안정적일지 판단 → 5. 문항 형태·채점 구조 설계 → 6. 문항 초안

## 검증용 기준 사례: 만든 사람(차주익)의 가치관

검사가 이 미묘함을 잡아내는지 확인하는 **테스트 픽스처**다. 이 결과가 "정답"이라는 뜻이 아니며, 전혀 다른 가치구조의 사람도 자연스럽게 다른 결과가 나와야 한다.

- 자기 행동과 감정은 본인이 책임진다. 상황은 행동을 **설명**하지만 **면책**하지 않는다.
- 혼자 있고 싶다고 하면 이유는 물을 수 있지만, 답하지 않으면 존중한다.
- 가까운 사람의 잘못된 선택도 충분히 조언한 뒤엔 그 사람 선택으로 둔다. 대신 결과의 책임을 대신 지지 않는다.
- 자기주장이 약한 것 자체는 결함이 아니다. 기질이면 존중.
- 여러 사람에게 호감을 받아도 상대를 면접 보듯 평가하기보다 호감에 감사하는 태도를 선호.
- "나와 안 맞는다"와 "그 사람이 부족하다"를 구분.
- 감정적으로 힘든 건 이해하지만 그걸 이유로 공격·통제하면 좋게 보지 않는다.
- 누가 운다고 그 사람 주장이 옳은 건 아니다.
- 사과는 말보다 이후 행동 변화. 반복되면 진짜 사과였는지 의심.
- 솔직하고 다소 거친 사람이 예쁘게 말하며 속을 숨기는 사람보다 편할 수 있다. 단, 내가 거친 표현을 허용하면 상대도 나에게 그래도 된다.
- 누군가 나에게 적용한 규칙은 그 사람에게도 적용 가능해야 한다.
- 거짓말 자체는 절대악이 아니다. 진실을 공개하지 않을 권리도 자율성. 단 거짓·왜곡을 책임회피·조종·자기합리화에 쓰는 건 매우 싫다.
- 성공·사교성·카리스마·적극성·재미는 좋은 특성이지만 인간적 가치판단에서 우선순위가 높지 않다.
- 깊은 관계를 만들 수 있으면 관계의 폭은 넓지 않아도 된다.
- 화가 너무 나면 "지금 화가 나서 나중에 얘기하고 싶다"고 말하고 자리를 뜨는 건 성숙한 절제.
- "내가 오해했다", "미안하다"고 말할 수 있는 능력을 높게 평가.
- 상대가 상처받았다고 하면, 내 행동이 객관적으로 잘못이 아니라고 생각해도 왜 그렇게 느꼈는지 대화해보고 조절할 수 있으면 조절한다.
- 남을 깎아내려 자존심을 지키는 태도를 싫어한다.
- (파일럿 1 후 추가) 내가 잘못하지 않았어도 상대가 아팠다면 **고통에 대한 사과**는 한다. 단 그건 잘못 인정이 아니다. "미안해 → 나는 이래서 이랬어 → 너는 어땠니"로 서로 맞춰가는 과정이 필요하다.
- (파일럿 1에서 드러남) 남의 사정은 봐주면서 같은 상황의 자신에게는 더 엄격하다.
- 특히 **위선, 수동공격성, 책임회피, 이중잣대**에 민감.

→ 예상 결: 책임 / 자율성 / 상호성 / 진정성 / 자기객관화 / 정서적 성숙 중시. 단순한 '착함' 중시가 아님.
