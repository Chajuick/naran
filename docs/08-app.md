# 08. 앱 v0.5 (2026-10-02)

서버 없는 정적 웹앱. Vite + React 19 + TypeScript + Zustand(persist, localStorage) + Vitest. 라우팅은 HashRouter(정적 호스팅에서 새로고침 404 방지).

## 실행
- `pnpm dev` — 개발 서버 (5173이 다른 프로젝트에 쓰이면 `pnpm dev --port 5931`)
- `pnpm test` — 채점 회귀 테스트 (시험판 v0.4.5와 28명 결과 일치)
- `pnpm build` — `dist/` 생성. 어떤 정적 호스팅에 올려도 됨(`base: './'`)

## 화면 (초기)
- **소개(처음 방문 시)**: ① 네 조각이 그려지는 인트로 "나라는 사람을 한 조각씩 채워가요" ② 이름 ③ 네 가지 검사 소개 ④ 다 모으면 할 수 있는 것 → 홈. 홈 하단 '나란 소개 다시 보기'
- 이름은 홈 인사("○○님을 채워가는 중이에요")와 AI 자료 호칭에 쓰임
- **홈**: 네 검사 카드(가치관 = 나란 검사, 성격·애착·기질 = 알고 있는 결과 입력) + 진행도 + "AI에게 줄 자료 만들기"
- **나란 검사**: 시험판과 같은 흐름(36문항 + 동점 시 순위), 선택지 순서 사람마다 섞고 고정, ⚐ 애매 표시
- **결과**: ① 유형 카드("당신은 ○○형" + 한 줄 + 설명 + 축 4칩) ② "그중에서도 나는" 헤드라인 ③ 판단할 때·관계에서·사람을 볼 때·나와 남의 기준 ④ 빛나요/조심해요 ⑤ 축별 근거 ⑥ 카드 순위·공정 카드 ⑦ **축별 자기평가**(1~5 + 실제 나는 더 왼쪽/맞음/더 오른쪽 — GPT 판정 권고, 파일럿 지표 4)
- **AI 자료**: 목적(전반/연애/갈등/일/스트레스) 선택 → 지침 + 나란 설명서·점수·근거·한계 + MBTI·애착·기질 + 교차 신호 → 복사

## 나라는 사람 (회차 기록, 2026-10-02)
- **회차(스냅숏)**: 검사를 마치거나 결과를 저장할 때마다 그 시점의 네 검사를 한 장으로 기록 (`src/lib/history.ts`, 테스트 `tests/history.test.ts`)
  - 일주일 안에 한 검사는 한 회차로 묶음(며칠에 걸친 종합 검사 = 1장)
  - 다시 하지 않았거나 다시 하는 중인 검사는 직전 회차 결과를 이어받음 ("6월에 가치관만 다시 → 나머지 4월 그대로")
  - 같은 결과를 다시 저장하면 회차를 만들지 않음. 회차 이름은 자동(종합 / 가치관 다시 …), 눌러서 바꿀 수 있음
- **/me 화면**: 완성 축하(네 조각 처음 다 채우면 1회) → 지금의 나 → 검사 사이에서 보이는 것(교차 신호) → 기록 보드(회차=열, 검사=행, 새로/유지 표시, 가치관 칸엔 4축 미니 막대) → 가치관 4축 변화 그래프 → 지난 회차와 달라진 점 → AI에게 분석 맡기기
- **AI 자료**: 2회차 이상이면 '변화 기록도 함께 넣기'(기본 켬) — 회차별 요약 + 변화 해석 요청(작은 점수 변화는 오차일 수 있다고 명시)
- 결과 화면 '처음부터 다시' → '다시 검사하기' (이번 결과는 기록에 남음)
- 개발 모드 전용 데모: `#/demo` 로 새로 열면 4월 종합 → 6월 가치관 다시(제3세트 58·69번 응답) 데모 기록을 넣음. **이 기기 저장 내용을 덮어씀.** 빌드엔 미포함

## 시험판 대비 바뀐 것
