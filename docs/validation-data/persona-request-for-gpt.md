가치관 검사 '나란'을 검증할 새 페르소나 32명을 만들어줘. 지난번처럼 "장면 + 말버릇"으로, 다른 AI가 이 인물이 되어 검사를 풀 거야.

[검사가 재는 4축] (−100~+100, |20| 미만은 균형)
- 책임 축: 책임(잘못엔 결과·책임을 먼저 본다) ↔ 이해(사정·성장 가능성을 먼저 본다)
- 경계 축: 자율(가까운 사람의 선택은 그 사람 몫) ↔ 보살핌(적극 개입해서 챙기는 게 맞다)
- 표현 축: 솔직(상대가 알아야 할 말은 한다) ↔ 조화(관계의 평온을 위해 덮어둔다)
- 감정 축: 구분(상대 감정이 결론에 들어가면 안 된다) ↔ 헤아림(상대 마음도 결정에 넣어야 한다)

[유형]
- 대표유형(책임×경계): A=책임+자율, B=책임+보살핌, C=이해+자율, D=이해+보살핌, E=둘 중 하나라도 균형(조율)
- 수식어(표현×감정): 1=솔직+구분, 2=솔직+헤아림, 3=조화+구분, 4=조화+헤아림

[만들 것] 총 32명
1. 정석형 16명: 대표유형 A·B·C·D 각각에 수식어 1·2·3·4를 하나씩 조합 (A1~D4). 특징을 뚜렷하게 → "분명한 사람을 제대로 잡는가"
2. 조율·경계형 8명 → "애매한 사람을 억지로 극단으로 밀지 않는가"
   - 책임 축만 중간 / 경계 축만 중간 / 표현 축만 중간 / 감정 축만 중간 (각 1명, 나머지 축은 뚜렷)
   - 두 축이 중간 (2명, 조합 다르게)
   - 네 축이 모두 중간 (1명)
   - 50~60대, 위계·연륜을 중시하는 사람 (1명)
3. 함정형 8명: 겉행동은 비슷하지만 동기가 다른 4쌍 → "그럴듯하지만 없는 특징을 만들어내지 않는가"
   - 말을 안 하는 두 사람: 관계가 상할까 봐 참았다가 나중에 차분히 말함 / 상대가 알아서 눈치채길 바라며 일부러 차갑게 굶
   - 도와주는 두 사람: 상대가 원할 때 적극적으로 도움 / 싫다고 해도 "널 위해서야" 하며 개입함
   - 감정을 중시한다는 두 사람: 상대 마음을 실제로 잘 읽고 결정에 반영 / 감정을 결정에 넣어야 한다고 말하지만 정작 남의 마음을 잘 못 읽고 자기 서운함에 휘둘림
   - 바른말 하는 두 사람: 상대를 위해 꼭 필요한 말만 함 / 솔직함을 내세워 상처 주는 말을 쉽게 함 (말로는 솔직이 옳다면서 실제로는 자기 화풀이)

[조건]
- 나이·성별·직업·지역을 다양하게. 20~40대에 몰리지 않게.
