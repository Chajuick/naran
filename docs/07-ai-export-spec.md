# 07. AI 전달 자료 설계 (초안, 2026-10-02)

## 궁극적 목표 (사용자)

> MBTI / 나란 가치검사 / 기질 / 애착유형 — 4가지 검사로 '나라는 사람'을 찾아간다.
> 전부 취합해 **AI에게 나를 분석할 수 있는 다방면의 자료**를 제공하는 앱. (나중엔 API 연결로 앱이 직접 분석)
> - 나라는 사람이 이 지표들에서 **모순되지 않는지** 볼 수 있어야 한다.
> - 나란 검사는 우리가 만든 지표라 AI가 모른다 → **이것만으로 이 사람을 충분히 자세히 설명**할 수 있게 넘겨야 한다. "포근한 돌봄형"이라고만 주면 AI는 뭔지 모른다.

## 검사별 역할 (겹치지 않게)
| 검사 | 묻는 것 |
|---|---|
| MBTI 스타일 | 어떻게 생각하고 정보를 다루는가 |
| 기질 | 자극에 어떻게 반응하는가 |
| 애착 | 가까운 관계에서 어떻게 연결되고 불안해하는가 |
| 나란 | 무엇을 옳다고 보고, 어떤 기준으로 사람과 상황을 판단하는가 |
| (후보) 갈등 대처 | 해결지향·유예·거리조절·횟수 기준 — 나란에 넣지 않음 |

## 설계 원칙

1. **공개 검사는 숫자, 나란은 설명서 + 숫자 + 근거.** AI가 아는 틀(MBTI·애착·기질)은 차원별 % 만으로 충분. 나란은 지표 정의 → 이 사람의 위치 → 그렇게 판단한 응답 근거 → 측정 한계 순서로.
2. **유형명은 요약일 뿐, 차원 점수가 본체.** AI에게는 '포근한 돌봄형'보다 '책임↔이해 +50 (이해 쪽), …'가 더 쓸모 있다. 유형명은 사람이 읽는 라벨로만 함께 준다.
3. **가치 ≠ 행동을 명시.** 나란은 '무엇이 옳다고 보는가'를 잰다. 기질·애착은 '어떻게 반응하는가'에 가깝다. 이 구분을 AI에게 알려야 모순과 긴장을 올바르게 해석한다.
4. **불확실성을 같이 준다.** 축당 4문항, 확신도, 균형 구간, 가상 검증만 거쳤다는 사실. AI가 과잉 해석하지 않도록.
5. **교차 검토는 AI 몫, 단서는 앱이 준다.** 앱은 미리 계산한 '교차 신호'(예: 미러에서 남에게 기대 큼 + 애착 불안 높음)를 표시하고, 해석은 AI에게 맡긴다.

## 모듈별 전달 항목

| 모듈 | 전달 | 비고 |
|---|---|---|
| MBTI 스타일 성격 | 4차원 각 % (E/I, S/N, T/F, J/P) + 4글자 | 아는 유형 직접 입력 or 자체 4축 검사(IPIP 기반). '공식 MBTI 아님' 표기 |
| 애착 | 불안 %, 회피 % + 4유형(안정·불안·회피·혼란) | ECR 2차원 구조. 문항은 자체 작성 |
| 기질 | 4차원 % (자극 추구, 위험 회피, 사회적 민감성, 인내력) | Cloninger 개념 참고, 문항 자체 작성 |
| **나란 가치검사** | 아래 '나란 블록' 전체 | 설명서 포함 |

## 나란 블록 구성

```
[나란 가치관·관계윤리 검사 — 지표 설명]
이 검사는 사람이 관계에서 '무엇이 옳다고 보는지'(가치 판단)를 잰다. 실제 행동이나 성격 반응은 재지 않는다.
양 끝이 모두 덕목인 4개 축 + 보조 지표 3개 + 입장 바꾸기(같은 상황을 남/나로 바꿔 묻기) + 우선순위 카드 2종.
- 책임 축 (책임 ↔ 이해): 잘못이 있을 때 결과·책임을 먼저 보나, 사정·성장 가능성을 먼저 보나
- 경계 축 (자율 ↔ 보살핌): 가까운 사람의 선택을 그 사람 몫으로 두나, 적극 개입해 챙기나
- 표현 축 (솔직 ↔ 조화): 상대가 알아야 할 말을 하나, 관계 평온을 위해 덮어두나
- 감정 축 (구분 ↔ 헤아림): 상대의 감정이 결론에 들어가지 않아야 하나, 들어가야 하나
- 보조: 상호성(나와 남에게 같은 기준을 요구하나) / 직접성(불만은 말로 꺼내야 한다고 보나) / 수정성(잘못 인정·바로잡기를 중시하나)
점수: −100(왼쪽 극) ~ +100(오른쪽 극). |20| 미만은 균형. 축당 4문항이라 정밀하지 않음 — 방향과 대략적 강도로만 해석할 것.

[이 사람의 결과]
유형: 포근한 원칙형 (사람이 읽는 라벨. 대표 유형 = 책임 축×경계 축, 수식어 = 표현 축×감정 축)
- 책임 축: −50 (약간 책임 쪽) · 응답 일관성: 대체로
- 경계 축: −87 (뚜렷하게 자율 쪽) · 일관성: 한쪽으로 모임
- 표현 축: +63 (뚜렷하게 조화 쪽)
- 감정 축: +63 (뚜렷하게 헤아림 쪽)
- 상호성 −0.25 / 직접성 −1.0 (침묵·말투로 하는 불만을 두 번 모두 '가장 덜 거슬림'으로 고름) / 수정성 +0.33
- 입장 바꾸기: 4쌍 모두 '남이 하면 더 엄격, 내가 하면 더 너그럽게' (남에게 거는 기대가 큼)
- 가장 거슬려 하는 것: 사과만 하고 반복 / 앞뒤가 다른 말 / 남의 호의를 당연시
- 사람을 볼 때 중시: 다정하게 챙겨줌 / 누구에게나 같은 기준 / 누구와도 잘 어울림
- 앱이 감지한 패턴: 서운함을 바로 말하기보다 속으로 삭이고, 상대가 먼저 알아주길 기대하는 쪽

[판단 근거가 된 응답 예시]
- "친구가 결혼할 사람에게서 걱정되는 점을 봤다" → "묻지 않는다면 굳이 먼저 꺼낼 일은 아니에요"
- "연인이 반나절 연락이 없었다" 남이면 '짧게라도 했어야'(4/5) ↔ 내가 하면 '바빴다면 그럴 수 있어요'(2/5)
- …

[측정 한계]
- 가치 판단 검사다. '조화를 옳다고 본다'와 '실제로 갈등을 피한다'는 다를 수 있다 → 기질·애착 결과와 함께 볼 것
- 축당 4문항, 우선순위 카드는 각 2회 노출. 아직 실제 사용자 데이터로 검증되지 않음 (가상 응답 검증만)
```

## 교차 신호 (앱이 미리 계산해 표시, 해석은 AI)

| 신호 | 의미할 수 있는 것 |
|---|---|
| 나란 감정 축 '구분' + MBTI F 강함 | 가치(결론은 내용으로)와 성향(감정 중시)의 긴장 — 머리와 마음이 다른 지점 |
| 나란 미러 '남에게 기대 큼' + 애착 불안 높음 | 기대가 말로 전달되지 않는 패턴의 가능성 |
| 나란 경계 '자율' + 애착 회피 높음 | 존중이 거리두기로 전달될 위험 |
| 나란 직접성 낮음 + 기질 위험 회피 높음 | 불만을 말하지 않는 이유가 가치보다 불안일 가능성 |
| 나란 책임 '책임' + 기질 인내력 높음 | 자기·타인 모두에게 높은 기준, 소진 위험 |

## AI에게 함께 줄 분석 지침 (00-brief의 프롬프트 지침 + 추가)
1. 유형명을 반복하지 말고 차원 점수와 근거로 설명할 것
2. 검사 간 **일치·모순·긴장**을 구분해서 짚을 것 (모순 = 측정 문제일 수도, 실제 내적 갈등일 수도)
3. 가치(나란)와 반응 성향(기질·애착)을 구분해서 해석할 것
4. 근거가 약한 부분은 추측이라고 명시, 병리화 금지
5. 연애·갈등·일·스트레스·의사결정 상황별로 구체화
